## 🚀 Getting Started

```bash
# Navigate to the app directory
cd artifacts/tractor-center

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📁 Project Structure

```

├── public/
```

## 🌐 SEO & AI Features

- ✅ Full **Schema.org** `LocalBusiness + AutoRepair` JSON-LD markup
- ✅ **`robots.txt`** for all major search engine crawlers
- ✅ **`sitemap.xml`** covering all page sections
- ✅ **`llms.txt`** for AI agent readability (ChatGPT, Perplexity, Gemini)
- ✅ **Open Graph** & Twitter Card meta tags
- ✅ **Geo-coordinates** pinned to Namakkal district
- ✅ Canonical URL, `sameAs` social profile linking
